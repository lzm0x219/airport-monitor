## Airport Monitor 适合你吗？

想知道机场套餐还剩多少流量，往往得打开网站、登录，再找到用量页面。Airport Monitor 把这些常看的信息放进菜单栏：

- **余额随时可见**：菜单栏显示剩余流量，点开查看套餐、下次重置、到期时间和同步状态。
- **多机场独立管理**：添加、编辑、暂停、归档与恢复，并选择菜单栏显示的机场。
- **同步与低余额提醒**：自动更新读数，失败时保留旧数；可启用本地低余额通知。

只要你的 HTTPS 订阅链接返回 `subscription-userinfo` 流量响应头，就可以尝试使用。无需配置 Surge HTTP API，也不依赖特定代理客户端。

当前源码已接入 Magpie 风格的原生多机场工作窗口：机场列表、设置和菜单栏共用本地数据。主界面按机场显示余额、每日用量统计与采样后预测。添加／编辑机场可设置流量重置规则、时间和时区，并预览下次重置。每个机场独立保存订阅与历史；菜单栏机场和主窗口浏览机场可以不同。当前为本地构建候选，尚未发布或获得用户视觉验收。

## 快速开始

**1 · 从源码构建。** 当前不保留预编译分发包。请按[构建说明](#从源码构建)生成 `Airport Monitor.app`，再放进「应用程序」后打开。

默认本地构建使用本机 ad-hoc 签名，未做 Developer ID 签名和 Apple 公证。其他 Mac 可能阻止打开；确认来源后，可在「系统设置 → 隐私与安全性」中使用「仍要打开」，或自行编译。

**2 · 添加机场。** 打开主窗口，点击「添加机场」，输入自己的 **HTTPS 订阅链接**并读取；核对预览、填写名称后确认添加。套餐名称为可选字段。已保存的链接不会回显。编辑时留空保留原链接；更新同一机场的链接保留历史，选择「更换数据来源」才开始独立历史。

**3 · 按你的习惯设置。** 从右上齿轮进入设置，按“通用”“菜单栏”“同步与提醒”“数据与隐私”“关于”分类切换，修改即时生效。默认每72小时同步，可选7天；手动刷新和失败重试也受同地址72小时间隔限制。机场自己的提醒与重置规则在配置中保存。

下次重置、到期日期与成功更新时间直接显示在主卡片，点击卡片可查看已用、上传和下载计数。重置按已有规则计算，未设置时明确标示；悬停可查看完整时间、规则与时区。底层采样和既有配置保留。

## 功能

### 菜单栏里看余额

选择「图标与余额」「仅余额」或「仅图标」，按习惯显示 GB 或 GiB。悬停查看更精确的余额、已用量和成功同步时间；右键可以立即同步、打开设置或退出。

面板可选“平面布局”和“分区卡片”，默认分区卡片，显示订阅额度、上传／下载、下次重置、到期时间和同步状态。右上提供刷新、打开主窗口和设置；余量计算说明在面板内打开，返回或 Esc 关闭。预测与历史分析不在菜单栏面板呈现。应用不会常驻 Dock。

### 主窗口管理机场

每个机场直接显示余量、重置、到期时间、同步状态及并排的用量统计和预测。预测依据最后一次有效采样，仅供参考；缺少每日记录不会显示为零。暂停与归档保留配置和本地数据，归档可恢复。

### 余额不足时提醒

按机场设置低余量、预计不足或到期提醒，通过 macOS 本地通知提示。提醒使用持久去重与冷却规则；状态恢复需要满足相应确认条件。

通知需要系统授权。提醒资格和显示预测分别计算。

### 同步失败也能看旧记录

请求失败时保留上次数据，同时显示错误和最后成功时间。读数超过30分钟会标为旧读数，主窗口区分限频等待、可刷新和同步失败。Mac 唤醒后按限频条件尝试同步；休眠和退出期间不采样。

## 数据留在哪里？

- **订阅链接**：保存在本机登录钥匙串，不写入偏好、历史文件或日志。
- **流量历史**：保存在本机沙盒目录，按来源分别记录，不含订阅 URL。实际路径见使用说明。
- **网络请求**：发往你填写的订阅地址及其 HTTPS 重定向目标。读取流量响应头后取消正文下载，不解析或保存节点列表；系统仍可能收到少量已在途正文。
- **分析与同步服务**：没有分析服务、远程遥测或 iCloud 同步。

更新同一机场的订阅 URL 会保留历史；选择「更换数据来源」后，新来源独立积累，旧历史仍可查看。损坏的历史不会被静默覆盖，可在设置中隔离原文件后重新开始。完整存储位置、请求规则和恢复方式见[使用说明](USAGE.md#隐私存储与故障恢复)。

## 从源码构建

建议使用 Xcode 26 或更新版本。打开 `AirportMonitor.xcodeproj`，选择共享 Scheme **AirportMonitor** 和 **My Mac**，按 ⌘R。无需第三方依赖、密钥或项目生成器。

也可以构建双架构 Release：

```sh
xcodebuild -project AirportMonitor.xcodeproj \
  -scheme AirportMonitor -configuration Release \
  -derivedDataPath /tmp/AirportMonitorBuild \
  'ARCHS=arm64 x86_64' ONLY_ACTIVE_ARCH=NO build
```

应用位于 `/tmp/AirportMonitorBuild/Build/Products/Release/Airport Monitor.app`。工程默认本机 ad-hoc 签名，向其他人发布时需自行配置 Developer ID 和公证。

核心逻辑与模拟网络测试：

```sh
swift test --scratch-path /tmp/AirportMonitorTests
```

| 目录 | 内容 |
| :-- | :-- |
| `Sources/App` | SwiftUI 面板与设置、菜单栏集成、钥匙串、本地通知 |
| `Sources/Core` | 响应头解析、采样账本、重置规则、预测、持久化与网络请求 |
| `Tests/CoreTests` | 核心逻辑与模拟网络测试，不访问真实机场 |
| `Tests/NativeModelTests` | 原生模型、菜单栏额度语义与多机场隔离测试 |
| `Design` | 猫头鹰06品牌源文件与资源生成工具 |

## 常见问题

**为什么读不到流量？**

订阅服务需要返回 `subscription-userinfo`。应用会在成功响应缺少该头时，以 Clash 客户端标识自动重试一次；两次都没有则提示缺失。401 / 403 或证书错误需检查订阅链接和服务商规则，应用不会跳过证书验证。

**为什么与机场网站的数字不同？**

先核对 GB / GiB 单位和更新时间。服务端计数可能有延迟，也可能包含多设备消耗与倍率。最终以机场账单为准。

**能显示实时网速或自动开机启动吗？**

当前没有实时速率或 Surge HTTP API 接入。设置提供“登录时启动”；开关已实现，系统注册与退出后重开效果仍需实机确认。

**还有哪些限制？**

详细的数据口径、通知去重和故障恢复见[使用说明](USAGE.md)。构建、测试及尚未完成的实机验证见[验证记录](VALIDATION.md)。
