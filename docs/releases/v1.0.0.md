Airport Monitor 将机场的剩余流量、重置和到期时间放在 Mac 菜单栏，也可以管理多个机场、回看用量并设置提醒。

## 这个版本可以做什么

- 在菜单栏查看主力机场的余量，打开面板查看套餐明细、重置和到期时间。
- 管理多个机场，为每个机场设置重置规则和提醒；暂停或移除后，历史记录仍会保留。
- 查看 7 天或 30 天的用量记录；设置重置规则后，还可以查看本周期。积累足够的有效读数后，可以参考用量预测。
- 开启系统通知后，可以设置低余量和到期提醒。
- 订阅链接保存在本机钥匙串，机场配置和历史也保存在本机。

## 使用前请注意

- 需要提供流量信息的 HTTPS 订阅链接。应用不会接管代理，也不导入节点。
- 同一订阅地址的两次读取至少间隔 72 小时；添加机场时的预览也算一次读取。Mac 休眠或应用退出期间不会采样。
- 预测仅供参考。预计不足提醒有独立的读数条件，仅靠每 72 小时采样无法触发。

## 安装与兼容性

需要 macOS 14 或更新版本。压缩包包含 Apple Silicon 和 Intel 两种架构；Intel Mac 上的实际运行尚未验证。

1. 下载 `Airport-Monitor-v1.0.0-macOS-universal.zip` 并解压。
2. 如果已有 Airport Monitor，先退出正在运行的应用。在访达中将下载版复制到「应用程序」文件夹；更新时请复制到旧版所在文件夹，并在提示时选择「替换」。
3. 打开应用。此版本未使用 Apple Developer ID 签名，也未经过 Apple 公证，macOS 可能提示无法验证。如果已确认下载来源可信且文件未被篡改，仍选择打开，可在「系统设置 → 隐私与安全性」中选择「仍要打开」，再按系统提示完成验证和确认。详见 [Apple 的说明](https://support.apple.com/zh-cn/102445)。

附件中的 `SHA256SUMS.txt` 可用于核对 ZIP：将两个文件放在同一目录，在该目录执行 `shasum -a 256 -c SHA256SUMS.txt`。

在一台 Apple Silicon Mac 上，从本地构建的 1.0.0 覆盖为下载版后，原有数据和设置保持一致，订阅仍显示已保存。此次未验证不同版本之间的升级、无数据的全新安装、真实联网刷新、登录启动或重启后体验；更新后钥匙串也可能要求重新授权。

更多设置和数据说明见[使用说明](https://github.com/lzm0x219/airport-monitor/blob/v1.0.0/docs/USAGE.md)。
