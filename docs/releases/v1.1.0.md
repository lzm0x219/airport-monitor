## 预计不足提醒

预计不足提醒现在可以使用 72 小时或 7 天间隔形成的有效采样预测。当按近期用量估计，重置前需要的流量达到当前剩余额度的 110% 时，应用会尝试发送提醒。预测需要足够的可比较读数和有效重置规则，不能保证发现两次采样之间的用量突增。

已提醒后，连续两次有效采样显示预计需求不超过余量的 90%，才允许同周期再次提醒；新周期重新积累出有效预测后会开启新一轮判断。低余量和用尽提醒继续独立工作。升级后保留已有配置和提醒记录，重新开启提醒或获得系统通知权限后等待新读数再判断。

## 安装与限制

需要 macOS 14 或更新版本。默认发布包使用 ad-hoc 签名，未经过 Apple Developer ID 签名和 Apple 公证；macOS 可能要求在「系统设置 → 隐私与安全性」中允许打开。为加载更新组件，应用关闭库验证；请从项目的 GitHub Releases 获取。应用数据保存在本机，更新后钥匙串可能要求重新授权。真实系统通知已在 Apple Silicon 上使用独立测试版和合成数据验证；正式发布包及真实订阅场景的通知、Intel Mac 实际运行尚未验证。跨版本更新已使用隔离的合成数据和本机测试源检查，真实数据及正式源的升级尚未验证。

安装及使用详情见[使用说明](https://github.com/lzm0x219/airport-monitor/blob/main/docs/USAGE.md)，验证范围见[验证记录](https://github.com/lzm0x219/airport-monitor/blob/main/docs/VALIDATION.md)。
