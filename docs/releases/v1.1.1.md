## 修复

修复将鼠标移至屏幕最顶部并再次点击菜单栏图标时，面板可能无法关闭的问题。

## 安装与限制

需要 macOS 14 或更新版本。默认发布包使用 ad-hoc 签名，未经过 Apple Developer ID 签名和 Apple 公证；macOS 可能要求在「系统设置 → 隐私与安全性」中允许打开。为加载更新组件，应用关闭库验证；请从项目的 GitHub Releases 获取。应用数据保存在本机，更新后钥匙串可能要求重新授权。

本次修复已在 Apple Silicon 上由用户实测；Intel Mac 实际运行尚未验证。安装及使用详情见[使用说明](https://github.com/lzm0x219/airport-monitor/blob/v1.1.1/docs/USAGE.md)。
