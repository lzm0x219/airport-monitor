## 更新

- 增加应用内更新。应用会定期检查已发布的新版本，下载并验证更新后提示重新启动；也可以在「设置 → 关于」中关闭自动检查或手动检查更新。
- 选择稍后更新后，可以继续使用应用，并在「关于」中重新启动安装；退出应用时也可能安装已下载的更新。

## 安装与升级

需要 macOS 14 或更新版本。压缩包包含 Apple Silicon 和 Intel 两种架构；Intel Mac 上的实际运行尚未验证。

1. 下载 `Airport-Monitor-v1.0.1-macOS-universal.zip` 并解压。旧的 1.0.0 版本不含更新器，需要先手动安装本版本。
2. 如果已有 Airport Monitor，先退出应用，再通过访达将下载版移动到旧版所在的「应用程序」文件夹，并选择「替换」。
3. 从安装目录打开应用。本版本未使用 Apple Developer ID 签名，也未经过 Apple 公证；如果 macOS 提示无法验证，请先确认下载来源可信，再在「系统设置 → 隐私与安全性」中选择「仍要打开」。详见 [Apple 的说明](https://support.apple.com/zh-cn/102445)。

如需核对下载，将 ZIP、`appcast.xml` 和 `SHA256SUMS.txt` 放在同一目录，在该目录执行 `shasum -a 256 -c SHA256SUMS.txt`。应用数据和设置保存在本机，更新后钥匙串可能要求重新授权。在一台 Apple Silicon Mac 上，隔离测试版已验证从 GitHub 下载更新并重启安装，空合成数据和显示设置保持一致。真实订阅、Intel Mac 和不同版本间的正式发布包升级尚未验证。

更多设置和数据说明见[使用说明](https://github.com/lzm0x219/airport-monitor/blob/d02d2a77e247055fc7d55a4f259b143a4581a599/docs/USAGE.md)。
