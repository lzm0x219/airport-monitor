这是一个维护版本，用于验证正式发布源的应用内升级。功能和本地数据格式与 1.0.0 相同。

## 更新和安装

已安装正式版 1.0.0 的用户可以等待自动检查，或在「设置 → 关于」中手动检查更新。下载并验证更新后，应用会提示重新启动；选择稍后后，也可以在「关于」中重新启动安装，退出应用时也可能安装已下载的更新。更新后钥匙串可能要求重新授权。

也可以下载 `Airport-Monitor-v1.0.1-macOS-universal.zip` 并解压。先退出旧版，在访达中将下载版移动到旧版所在的「应用程序」文件夹，并选择「替换」，再从安装目录打开。

需要 macOS 14 或更新版本，安装包包含 Apple Silicon 和 Intel 架构；Intel Mac 上的实际运行尚未验证。

本版本未使用 Apple Developer ID 签名，也未经过 Apple 公证。macOS 可能提示无法验证；确认下载来源可信且文件未被篡改后，如仍选择打开，可在「系统设置 → 隐私与安全性」中选择「仍要打开」，再按系统提示完成验证。详见 [Apple 的说明](https://support.apple.com/zh-cn/102445)。为加载更新组件，应用关闭了 macOS 的库验证，加载动态库时少了一层系统校验。请从本项目的 GitHub Releases 下载。

如需核对下载，将 ZIP、`appcast.xml` 和 `SHA256SUMS.txt` 放在同一目录，在该目录执行 `shasum -a 256 -c SHA256SUMS.txt`。

应用数据和设置保存在本机。正式源跨版本升级和真实订阅联网刷新的实机验证范围见[验证记录](https://github.com/lzm0x219/airport-monitor/blob/main/docs/VALIDATION.md)，安装及使用详情见[使用说明](https://github.com/lzm0x219/airport-monitor/blob/main/docs/USAGE.md)。
