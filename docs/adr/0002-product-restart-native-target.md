# 产品重启后的原生实施目标

Date: 2026-10-23
Status: 历史规划；现行范围见 [PRODUCT.md](../../PRODUCT.md) 和 [USAGE.md](../../USAGE.md)。

## 背景

用户已要求整理当前设计及产品规则、核对原生差距并形成可执行方案；状态栏面板保持不变。浏览器原型已演进至v63，旧ADR的主页面范围、换链接和预测口径与目标不同。

## 决定

以当时的产品与设计基线作为实施目标入口，结合差距表和实施方案确定顺序与验收。这些历史资料已移入废纸篓；现行产品说明见[PRODUCT.md](../../PRODUCT.md)与[USAGE.md](../../USAGE.md)。

继续原生SwiftUI／AppKit；复用网络解析、钥匙串、文件保护和重置计算，不把合成浏览器数据或简化时区算法移入生产。先完成来源身份、提交恢复及同步生命周期，再做统计预测、提醒和UI接入。

目标采用全机场双图主页面、原位预览添加、配置弹窗直接取消、同源链接保历史／显式新源分段，以及连续观测区间预测。通知有全局／机场／类型作用域和持久事件；旧GB阈值、重置种类及原始账本受迁移保护。详细默认值不是已经经过真实数据优化的结果。

## 对旧决策的影响

[ADR0001](0001-native-magpie-model-boundaries.md)继续描述旧原生实现；其中主页面不显示图表、浏览机场选择、三有效日预测与换链接一律分账的目标地位被本决策替代。其原生技术路线、秘密隔离、演示副作用隔离和状态栏面板设计仍保留。

本决策为实施规划，不宣称新功能已完成，不授权发布。来源迁移和状态栏回归是交付前置条件。
