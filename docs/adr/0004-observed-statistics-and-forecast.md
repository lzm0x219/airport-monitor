# 观测区间统计与连续序列预测

Date: 2026-10-23
Status: implemented-candidate

对应当时的原生统计任务。原始Ledger、配置及迁移格式保持，该轮未部署或操作真实用户数据。

2026-10-27 后主窗口另用采样后预测，通知仍使用本决策的连续预测资格；现行展示口径见[使用说明](../../USAGE.md#用量统计与预测)。下文保留该决策作出时的背景。

## 统一来源

统计与预测共用相邻样本分类器。区间身份由两端sampleID组成，重算／重启不生成新身份。上传和下载各自比较；任一回退、额度改变、已知重置、跨规则版本或不递增时间均不能作为普通消耗。先以整数计算分量差再转Double，避免大计数丢失微小增量。仅到期日期延长不自行推断计数重置。

完整包含于筛选范围的可比较区间才进入汇总，右端允许恰好相等；跨界区间不按时间比例摊分。同日及恰次日零点结束的区间归开始日，其余跨日差额进入未分配集合。缺记录是nil，确有观测且差额为零才是0。空范围没有日项或用量。

日期划分使用v2快照保存的统计时区，规则计算继续使用各ResetRule自身时区，两者职责不同。夏令时日期可能为23或25小时，不硬编码自然日秒数。读取报告不修改样本、配置或持久化状态。

## 规则生效端点

初始版本的effectiveAt=nil表示迁移前规则的真实生效时间未知。后续版本只从明确生效时刻使用。规则保存不重算已完成区间：区间结束恰等于规则生效时刻仍使用旧规则；仅内部跨版本的区间不可比较；从生效时刻开始的区间使用新规则。已知计划重置与配置修改不同，计划重置恰在区间结束时仍排除该区间。

修改规则持久化needsVerification；失败或重启不消除。预测在有效新读数后使用新规则生效后的连续序列，不能借边界恰在样本点而混入旧版本凑足历史。历史统计仍保留可比较的已完成区间。

## 预测资格与时间锚点

使用最近7×24小时内最新连续可比较序列，不插值窗口起点，不跳过中间断点去寻找更早的足量数据。跨度至少72小时、至少4次读数、覆盖至少3个统计日期；相邻超过24小时切断预测序列，但不丢弃仍可比较的累计历史差额。

日均＝观测增长／实际经过秒数×86400。仅预测至有效下次重置；到期不晚于重置、未知余量、无有效重置、零增长或历史不足时不输出确定够用结论。失败、暂停、归档、同步中、待核对、未来时间及超过max(30分钟,3×同步间隔)的读数使当前预测不可用。

耗尽时间、重置时余量与预测线锚定最后成功读数的时刻和余额，不随UI刷新平移。结果附带generatedAt、实际观察起止、样本数及具体不可用原因。historicalForecastResult按最后成功读数时刻及当时规则重算旧估计，供历史查看，不参与当前风险或通知。

余额图的真实观测连线继续保守地在超过两次采样间隔处断开；这是展示采样缺口，不是预测24小时资格门槛。图表预测部分必须消费相同ForecastResult，不能另算一套结论。

## 兼容与后续

旧UsageSummary及ForecastReason保留供既有调用；新界面应消费UsageReport的可选bytes、unallocated／partial／excluded，以及ForecastDiagnostic，不把兼容字段0或泛化reason当成完整含义。ForecastEstimate.coverage仅是兼容字段，不代表概率或置信度。

主页面预测文案随规则同步；状态栏的额度呈现、共享风险色和重置展示保持独立。现行界面和验证范围分别见[设计规范](../../DESIGN.md)与[验证记录](../../VALIDATION.md)。
