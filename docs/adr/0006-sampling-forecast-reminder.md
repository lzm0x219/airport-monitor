# 基于采样后预测的预计不足提醒

Date: 2026-11-04
Status: implemented-candidate

本决策替代 [0005](0005-reminder-policy-and-delivery.md) 中预计不足使用连续预测和两次触发确认的部分；低余量、用尽、到期和其他投递保护继续适用。

预计不足使用有效采样后预测，新保存的成功读数在预计到计划重置的需求达到剩余流量 110% 时即可形成提醒候选。已提醒后，连续两次不同的新读数估计需求不超过剩余流量 90% 才解除；风险持续加重不重复提醒。保留 24 小时冷却和冷却后新读数要求。无预测资格、关闭或授权不足不会当作风险解除；重新开启或获得授权后等待新读数。

计划重置不是确认服务商实际重置。跨计划重置后的首次有效新预测开始新的风险判断；修改规则只从生效时刻采用新规则，并保留既有去重，规则生效前的历史重置不是新周期。按来源和风险轮次记录通知归属，未知投递结果保守去重，迟到回执只更新原轮次；旧版未知周期状态保守迁移。失败重试重新判断有效原因，不因重试额外读取订阅。候选通过权限检查后、发送意图落盘前发生中断时，按已保存的授权检查和候选身份重新核对；系统拒绝或候选失效时取消，不把旧读数当作新观察。

预测仅依据历史观测，不能保证捕获两次采样之间的流量突增，也不能保证通知展示或已读。功能验证范围以 [VALIDATION.md](../VALIDATION.md) 为准。
