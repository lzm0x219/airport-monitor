## 数据与状态边界

`AirportWorkspace`管理机场目录、菜单栏机场与浏览机场；每机场由独立`MonitorModel`保存账本、重置规则与同步尝试。新链接进入独立钥匙串账户，新历史以随机UUID标识；旧`active-url`、偏好及历史ID兼容读取。归档暂停同步而保留本地配置和文件。

主窗口通过BasicQuotaPresentation按实际余量、GB阈值、到期和同步状态呈现；预测不参与主卡片、关注筛选或系统状态项。菜单栏两版共用服务器总额与剩余量，并按剩余比例20%／50%分档。单位或已用／剩余切换不改变分档，未知总额不推断比例。菜单栏的比例风险不替代主窗口GB阈值或通知条件。

预测只接受本周期最近七天中覆盖合格的已结束自然日，至少三天；没有跨周期补充依据。计数回落表示重置或修正，不能仅凭它确认服务商完成真实周期重置。当前通知去重会在计数回落或余额恢复到阈值以上后重新布防，这是现有实现边界。

## 界面与副作用边界

主窗口聚焦基础余量和多机场管理，设置收敛为单页；预测、近期用量、历史分析、图表和日期筛选暂从界面移除。独立记录页与CSV导出已删除，底层采样、计算、配置和同步诊断保留。菜单栏展示订阅、额度、上传／下载、下次重置、到期与同步状态，不再显示预测或历史图。2026-10-20恢复添加／编辑表单的重置规则设置，复用ResetRule与每机场偏好持久化，不迁移其他候选主界面布局。

原生说明在当前面板内打开，背景暂停交互与辅助暴露；返回／Esc关闭说明，再关闭面板。具体桌面焦点与偏好重开仍按[验证记录](../../VALIDATION.md)列明边界。

多机场目录与历史分别持久化；钥匙串写入失败保留旧配置，保存成功但请求失败属于“已保存、同步失败”。旧账本不补造同步尝试。演示模式在模型创建时隔离网络、秘密和历史访问，并禁用通知、登录启动和保存。

旧视觉参考已移出项目；这不改变数据所有权和原生技术路线。构建、自动测试、原生快照及用户视觉接受分别记录。
